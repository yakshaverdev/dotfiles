# Global response style

Use ASD-STE100 Simplified Technical English for all responses. Use short, direct sentences and one main instruction per sentence. Prefer common words, active voice, and consistent terms. Do not use contractions, idioms, or needless synonyms. Keep code, commands, technical identifiers, proper names, and verbatim quotations unchanged.

# Reviews

When a brief asks you to review a spec or a code change, you are the reviewer: report findings and leave the files as they are. Grade each finding by the dimensions and the severity scale in `~/.agents/skills/first-draft/dimensions.md`, unless the brief includes them. Check correctness and running cost. Give evidence (`file:line`) and a concrete scenario for each finding.
